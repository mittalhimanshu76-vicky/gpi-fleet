# GPI Fleet

## Product Vision

GPI Fleet is a fleet management platform designed for small and medium-sized transport businesses.

The goal is to provide a simple, professional system for managing fleet expenses, vehicles, drivers, fuel, maintenance, reports, and business operations.

The product is being designed as both:

1. A commercial Flutter application.
2. A premium Fleet Management Notion template.

## Target Customers

- Small transporters
- Medium-sized fleet owners
- Truck operators
- Logistics businesses
- Fleet managers

The product should eventually support fleets ranging from a few vehicles to larger commercial fleets.

## Core Problems

Transport businesses often manage fleet information using:

- Paper records
- WhatsApp
- Excel spreadsheets
- Multiple disconnected applications

GPI Fleet aims to bring these workflows into one simple system.

## Product Principles

Every feature should be evaluated for:

1. Commercial value
2. Customer usefulness
3. Scalability
4. Notion template potential
5. Reusability
6. Maintainability

Avoid unnecessary feature bloat and cosmetic development that does not materially improve the product.

## Technology

- Flutter
- Dart
- SQLite/local database
- Material 3
- PDF generation
- Excel generation
- Native file sharing

## Development Philosophy

Build one stable module at a time.

For every milestone:

Design → Develop → Test → Analyze → Commit → Push

Stable functionality should not be unnecessarily rewritten.

## Long-Term Vision

The long-term goal is to evolve GPI Fleet from an expense management application into a complete Fleet Operating System for transport businesses.
